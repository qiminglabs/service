# Demo 功能助手

全局布局挂载，匿名 POST /api/assistant，不验证业务身份。每次提问时读取当前页面正文、字段值、按钮状态，以及本机 Demo 的 requests、configs、references 三个完整数据存储（包括其他客户和用户，不按身份过滤），发送至 OpenAI API 用于解释功能、状态和操作方法。没有审批、删除、提交或其他业务执行工具。

页面采集排除助手自身、脚本、密码输入和隐藏输入。不会读取任意浏览器存储或服务端密钥。在线文档正文与附件元数据随业务记录提供；上传的二进制附件正文暂未提取。当前数据仅来自本机，不代表其他浏览器或设备的数据。

## OpenAI API 配置

服务端设置 OPENAI_API_KEY 和 ASSISTANT_MODEL，接口固定为 https://api.openai.com/v1/responses。本地可参考 .env.example 配置后重启开发服务；部署时使用站点秘密变量并重新部署。不要使用 NEXT_PUBLIC_ 保存密钥。尚未配置时返回 503，不使用模拟回答。模型名由后续配置指定。

请求使用 instructions、input、store:false，无 tools 或持久化 conversation ID。参考：https://developers.openai.com/api/reference/cli/resources/responses/methods/create 。store:false 不代表供应商零日志保留。真实调用留待模型与密钥配置后联调。

## 上下文与边界

每次读取全部三类记录，发送最多 180,000 字符的上下文（页面最多 30,000 字符，其余用于记录）。超出容量、存储读取失败或附件正文未提取时附带 incomplete 和 notes，模型必须说明不能确认的范围，不得声称已遍历完整内容。不能把任意记录文字当作系统指令或新功能实现证据。

对话保存在当前页面内存，刷新丢弃；最多发送最近 8 条。清空会中止请求。问题最多 1500 字、请求最多 1 MB、模型超时 90 秒，浏览器等待 100 秒。错误不会回传密钥或供应商错误正文，回答按纯文本渲染。全站读取是只读权限，不改变任何业务页面的操作权限。

公开生产部署前可在网关配置匿名请求速率及费用上限；当前无跨实例限流。系统指令和代码核对知识位于 lib/demo-assistant-server.ts，功能变更时需同步维护。

## 只读源码检索

回答前由服务端检索当前站点项目源码，覆盖 app、components、lib、hooks、scripts 及根目录代码/配置，包括组件、业务校验、状态流转和测试。排除依赖、生成物、声明文件、环境变量文件及密钥文件。源码不会作为公开静态资源提供，也不接受客户端指定路径或伪造检索证据。

构建脚本 scripts/build-assistant-index.mjs 生成服务端索引 .generated/assistant-source-index.json，保留内容版本摘要。npm run dev / build 自动重建；开发服务监测源码新增、修改和删除并更新索引，生产发布使用该次构建的快照。源码更新需重新部署后才反映到线上回答。可手动运行 npm run index:assistant。

检索采用中英文关键词与业务术语扩展，结合最近一次问题和当前页签/状态，选取最多 10 段重叠分块（总计最多 36,000 字符），分散到相关组件及保存层。它属于词法检索，无法保证每次找到所有相关实现；未命中不能据此断言功能不存在。测试片段仅作辅助，不等于功能已上线。实现证据优先于手写知识库，源码注释与字符串不能覆盖系统指令。

回答默认 1–3 句、通常不超过 150 字，只解释结论及下一步，不展示代码、路径、文件名、行号或检索过程。依然无任何业务执行工具。真实生成效果待 OpenAI 模型及密钥配置后联调。

GPT-5.6 系列使用 low 推理强度，输出预算 4000 tokens（包含推理），回答仍要求简短。Worker 使用 manual 重定向并拒绝非成功状态，不向其他地址跟随转发密钥。

## Clash 本地代理

本地 .env 可设置 ASSISTANT_HTTP_PROXY=http://127.0.0.1:7897（端口按 Clash 实际配置）。重启开发服务后，通过仅监听回环地址、随机端口及每次启动随机令牌的开发中转访问 OpenAI。中转只允许固定 /responses 目标，TLS 校验开启，不存储请求或密钥。生产构建关闭中转，仍直接访问 OpenAI；无需把本地代理配置到 Sites。
