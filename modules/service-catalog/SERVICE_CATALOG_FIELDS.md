# 服务目录对象字段表

本文件是 `ServiceCatalog` 对象的字段单一事实源。后续服务申请、服务项目、派单、工单、核算，以及管理后台的列表、表单、详情页和接口设计，都必须使用本字段表中的名称、类型、枚举与校验规则。

## 字段定义

| 标准字段名 | 中文名称 | 类型 | 创建必填 | 来源 | 规则与说明 |
| --- | --- | --- | --- | --- | --- |
| `serviceCatalogId` | 服务目录 ID | UUID / ID | 系统 | 系统生成 | 内部主键，全局唯一，不向普通用户编辑 |
| `version` | 版本号 | Integer | 系统 | 系统生成 | 从 `1` 开始，展示为 `v1`；目录内容、启停状态或任一申请配置发生实际变更后递增；不可手动编辑 |
| `serviceCode` | 服务编码 | String | 系统 | 系统生成 | 格式 `SC-{类别码}-{序号}`，全局唯一，创建后不可修改 |
| `serviceCategory` | 服务类别 | Enum | 是 | 用户填写 | 仅允许使用“服务类别”枚举 |
| `serviceName` | 服务名称 | String(80) | 是 | 用户填写 | 去除首尾空格后不能为空；用于申请和工单展示 |
| `serviceDescription` | 服务说明 | String(255) | 是 | 用户填写 | 说明服务范围、交付边界与成功标准 |
| `pricingUnit` | 计价单位 | Enum | 是 | 用户填写 | `服务人天`、`巡检权益`、`升级权益` |
| `pricingCoefficient` | 计价系数 | Decimal(5,2) | 是 | 用户填写 | 大于 `0` 且不超过 `999.99`；最多两位小数；列表固定显示两位小数 |
| `defaultPricingQuantity` | 默认计价数量 | Decimal(5,2) | 是 | 用户填写 | 大于 `0` 且不超过 `999.99`；最多两位小数 |
| `supportedServiceMethods` | 支持服务方式 | Enum[] | 是 | 用户填写 | 至少选择一项；可选 `远程`、`现场` |
| `certificationRequirements` | 认证要求 | String[] | 是 | 用户填写 | 至少选择一项；`无认证要求` 与其他认证互斥 |
| `supportedProviders` | 支持服务方 | Enum[] | 是 | 用户填写 | 至少选择一项；可选 `原厂`、`代理商`、`服务商` |
| `allowedInitiatorSites` | 可发起站点 | Enum[] | 是 | 用户填写 | 至少选择一项；可选 `内部系统`、`客户中心`、`合作伙伴中心` |
| `status` | 状态 | Enum | 系统 | 系统维护 | `草稿`、`已启用`、`已停用`；创建后默认为 `草稿` |
| `internalNote` | 内部备注 | String(255) | 是 | 用户填写 | 仅内部角色可见；创建时必须填写 |
| `createdBy` | 创建人 | User ID | 系统 | 系统记录 | 不可编辑 |
| `createdAt` | 创建时间 | DateTime | 系统 | 系统记录 | ISO 8601，展示时按用户时区格式化 |
| `updatedBy` | 上次修改人 | User ID | 系统 | 系统记录 | 不可编辑 |
| `updatedAt` | 上次修改时间 | DateTime | 系统 | 系统记录 | ISO 8601，展示时按用户时区格式化 |

## 服务类别

| 服务类别 | 类别码 | 编码示例 |
| --- | --- | --- |
| 产品实施交付 | `IMP` | `SC-IMP-001` |
| 产品增值服务 | `ADV` | `SC-ADV-001` |
| 运维支持或培训 | `OPS` | `SC-OPS-001` |
| 技术保障或支持 | `SUP` | `SC-SUP-001` |

序号从 `001` 开始按类别递增，超过 `999` 后扩展为四位，最大为 `9999`。编码仅由系统生成，前端、接口调用方和导入流程均不得自行指定或修改。

## 状态规则

### 版本管理

- 每次实际变更原子保存目录、内部申请配置及客户中心申请配置的完整快照；无内容变化不增加版本。
- 历史版本只读，包含当时的字段配置、材料要求、上传模板文件及在线模板链接；外部在线文档仅保存链接，不冻结第三方文档正文。
- 存量目录从当前状态建立 v1，无法追溯版本管理上线前的修改。
- 两套申请配置独立维护，当前服务申请继续引用内部申请配置；已有申请项快照保持不变。

```text
创建 → 草稿 → 已启用 ⇄ 已停用
         └─ 删除
```

- 仅草稿可以删除。
- 已启用过的记录不能退回草稿。
- 草稿启用前必须通过必填字段、数值范围、枚举值和模板分配检查。
- 停用只影响新申请和新工单，不改变历史业务记录中的服务目录快照。

## 派生信息与关联对象

以下内容可在服务目录页面展示，但不属于 `ServiceCatalog` 对象字段，不得混入本字段表：

- 模板版本、步骤数量：来源于服务模板及模板分配关系。
- 默认核算结果：`pricingCoefficient × defaultPricingQuantity`，为计算值。
- 申请数、项目数、工单数：来源于下游业务对象的统计值。
- 服务模板、模板步骤：使用各自独立对象保存，通过模板分配规则与服务目录关联。

## 设计与实现约束

- 页面文案统一使用“计价系数”，不得替换为“计价方式”。
- 列表、创建表单、编辑表单、详情页、筛选条件、接口字段和测试数据必须与本表一致。
- 创建操作要求填写本表中所有“用户填写”字段；系统字段由系统自动补齐。
- 下游对象引用服务目录时，至少保存 `serviceCatalogId` 和当时的服务目录必要快照，避免目录后续修改影响历史记录。
- 新增、删除或修改字段前，应先更新本文件，再同步 PRD、页面、接口和数据模型。
