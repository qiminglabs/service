# Master Data

负责维护 Demo 业务流程引用的客户、联系人、服务资产、业务对象、内部用户、合作伙伴、合作伙伴用户和服务认证主数据；不连接 CRM、CMDB 或外部资产系统。

## 设计基准

- [`MASTER_DATA_FIELDS.md`](./MASTER_DATA_FIELDS.md)：主数据对象字段的单一事实源。后续相关页面、表单、接口、数据库和测试数据必须遵循该字段表。

## 模块边界

- 模块内定义客户、联系人、服务资产、业务对象、内部用户、合作伙伴、合作伙伴用户、服务认证及其关联和校验规则。
- Demo 页面只维护和引用这些数据，不在页面层重新定义字段。
- 本地 Demo 右上角切换身份从本模块的联系人、内部用户和合作伙伴用户读取姓名与 ID；角色规则仍属于身份与权限层，不在菜单中独立虚构人员。
- 数据库种子入口位于 `packages/database`，端到端场景构造位于 `packages/testkit`。
