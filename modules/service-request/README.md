# Service Request

服务请求承载整体申请，申请项承载具体服务范围、参数和评估材料。

## 设计基准

- [`SERVICE_REQUEST_FIELDS.md`](./SERVICE_REQUEST_FIELDS.md)：服务申请、申请子项、业务对象关联、状态和校验规则的单一事实源。
- [REQUEST_ITEM_MATERIALS.md](./REQUEST_ITEM_MATERIALS.md)：本版申请项、材料和本地保存说明。

## 第一版边界

- 目标状态为：草稿 → 待评估 →〔待审批：仅特批路径〕→ 待确认 → 待受理 → 已转服务项目，另有已取消。
- 内部审批先于正式客户确认；特批拒绝后保留拒绝记录，请求回待评估；PMO 可取消不再继续的请求。排期由工单处理。
- 只支持本地处理，不连接 CRM、客户中心或外部额度系统。
- 草稿允许零个申请项，提交时至少一个；同一服务目录可重复添加。
- 业务对象可不选，也可关联同一客户下的多个业务对象。
- 本版支持草稿创建、申请详情、申请项基础信息弹窗、申请详情页分项补充材料、按目录配置必填参数及材料模板、文件版本上传下载和整单校验提交。
- 草稿、文件和目录申请配置保存于本机浏览器。列表只显示记录状态，不展示流程步骤条。
- 提交后进入待评估并锁定申请内容；评估、审批、确认、额度处理及工单生成操作尚未接入。
