# 服务管理系统 Executable Prototype

当前阶段只完成第一版业务闭环的模块拆分，不安装技术框架、不建表、不写页面、接口或业务功能。

第一版唯一主链路：

```text
销售提交服务申请
-> 项目经理审批
-> 转服务项目并自动生成 2 个工单
-> 项目经理派单
-> 工程师执行步骤
-> 上传交付物
-> 填写工时
-> 项目经理复核
-> 客户确认
-> 项目完成
```

目录分为：

```text
apps/       未来的 Web 与 API 运行入口
modules/    第一版业务模块，每个模块一个独立目录
packages/   数据库、公共契约、Demo 身份与测试基础包
infra/      PostgreSQL 运行配置目录
docs/       模块边界说明
```

详细模块清单见 [docs/module-map.md](docs/module-map.md)。

第一版明确不做 Salesforce/CRM、资产系统、企业微信或手机号认证、邮件、腾讯会议、对象级复杂权限、SLA 引擎、不可篡改审计、对象存储和 AI。
